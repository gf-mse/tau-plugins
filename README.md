# tau-plugins
_(mostly tui) plugins for huggingface/tau agent_

Setting examples assume Unix/Linux/MacOS

## installation

Every directory under `src/` is a plugin; copy it into `~/.tau/extensions/` to install:

```sh
# install 'invoke_editor' plugin
cp -a src/invoke_editor ~/.tau/extensions/
```

Now run or restart `tau` to use the plugin.
